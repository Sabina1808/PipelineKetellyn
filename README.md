# PipelineKetellyn

Prática guiada "Minha Primeira Pipeline Segura" (Fatec, Desenvolvimento de Sistemas).

Aplicação Flask protegida por uma pipeline do GitHub Actions com:

- Testes automatizados (pytest)
- CodeQL (análise de segurança do código)
- Busca de segredos (detect-secrets)
- Revisão de dependências (Dependabot)
- Deploy simulado no ambiente `staging`
